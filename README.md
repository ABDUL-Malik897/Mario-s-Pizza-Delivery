# Mario's Pizza Online Ordering System

## Description

This is a React-based pizza ordering application. Users can customize a pizza, select toppings and sides, choose delivery or pickup, and see the total price update as they make changes.

## Features

- Select pizza size
- Select crust type
- Select pizza quantity
- Select multiple toppings
- Select sides and drinks
- Delivery or pickup option
- Dynamic price calculation
- Order validation
- Order summary
- Clear order button
- Order confirmation receipt
- LocalStorage for the last order

## Technologies

- React
- JavaScript
- HTML
- CSS

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Install dependencies:

   npm install

4. Start the application:

   npm start

5. Open the localhost URL shown in the terminal.

## React Concepts Used

- useState
- Controlled form inputs
- Conditional rendering
- Event handling
- Array methods
- Form validation
- localStorage
